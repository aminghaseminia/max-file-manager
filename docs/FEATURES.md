# Directory Opus feature matrix → max-file-manager

مرجع: امکانات Directory Opus 13 (ویندوز). ستون «فاز» یعنی کِی نوبتش می‌شود؛ هر چیزی که تیک ندارد هنوز پیاده نشده است.

## فاز ۱ — هستهٔ یک فایل‌منیجر روزمره ✅

- [x] دو پنجرهٔ مستقل (مبدأ / مقصد)
- [x] تب در هر پنجره؛ نوار تب با یک تب پنهان می‌شود (تنظیم، پیش‌فرض روشن) و دکمهٔ تب نو در نوار مسیر می‌ماند
- [x] مرور واقعی پوشه، breadcrumb، بالا/رفرش، Backspace
- [x] لیست ستون‌دار با مرتب‌سازی و «پوشه‌ها اول»
- [x] لیست مجازی‌شده — پوشهٔ ۱۰۰هزار فایلی روان بماند
- [x] انتخاب تک/چندتایی (Ctrl، Shift)
- [x] کپی F5 · انتقال F6 · پوشهٔ نو F7 · سطل بازیافت F8 · حذف قطعی Shift+F8 · تغییر نام F2
- [x] نمایش/پنهان‌کردن فایل‌های مخفی (Ctrl+H) — پوشه‌هایی که با `hidden` در `.mfm.json` از فهرست پنهان شده‌اند هم با همین کلید دیده می‌شوند (کم‌رنگ + نشان چشم)
- [x] تم تیره/روشن/سیستم (سیستم روشن/تیرهٔ سیستم‌عامل را زنده دنبال می‌کند)
- [x] ستون‌های نمای details: روشن/خاموش با راست‌کلیک روی سرستون و تغییر عرض با کشیدن لبهٔ سرستون (عرض‌ها ذخیره می‌شوند)
- [x] زیرنویس بندانگشتی: انتخاب فیلدها برای نمایش کوچک و کم‌رنگ زیر نام فایل، هر فیلد در یک خط جداگانه، از منوی ستون‌ها و تنظیمات
- [x] فیلتر نام شناور در پایین-راست پنل، فقط وقتی باز است یا فیلتر فعالی دارد؛ دکمهٔ قیف جای آن در نوار آدرس است (Ctrl+F بازش می‌کند، Esc می‌بندد)
- [x] انتخاب چندتایی با کشیدن مستطیل روی فضای خالی (Ctrl نگه‌داشتن، انتخاب قبلی را اضافه می‌کند)
- [x] چسباندن تصویر از کلیپ‌بورد (Ctrl+V) به‌صورت فایل در پوشهٔ جاری، با نام یکتا و انتخاب خودکار فایل تازه
- [x] عرض پنل پیش‌نمایش/ادیتور در تک‌پنجره و دو‌پنجره با کشیدن جداکننده تغییر می‌کند و ذخیره می‌شود
- [x] اندازهٔ کاشی‌های نمای بندانگشتی با Ctrl + چرخ ماوس (۸۰–۲۴۰px، همان تنظیم tileSize)
- [x] منوی راست‌کلیک گروه‌بندی‌شده: چهار زیرمنوی «عملیات فایل / پوشه و نمایش / مسیر و سیستم / برچسب و جزئیات» + «خروجی فهرست»؛ منوی اصلی کوتاه می‌ماند و با هاور/کلیک باز می‌شود؛ اگر یک طرف جا نباشد زیرمنو در سمت دیگر باز می‌شود و روی منو نمی‌افتد
- [x] پنجرهٔ «ویژگی‌ها» تب‌بندی‌شده مثل Dolphin (منو یا Alt+Enter):
  - **عمومی**: آیکون/بندانگشتی، نام قابل‌ویرایش (تغییر نام با Enter/بلور)، نوع، MIME، «باز کردن با» + «تغییر…»، مسیر کامل با کپی، اندازهٔ خوانا و بایت دقیق، ابعاد تصویر، هدف پیوند، سه زمان
  - **دسترسی‌ها**: جدول مالک/گروه/بقیه با «می‌تواند مشاهده و تغییر دهد / فقط مشاهده» (chmod واقعی)، اجرا‌پذیر، مالکیت با نام و شناسه، مجوز پیشرفتهٔ سه‌رقمی، لینک سخت و inode/device
  - **چکیده**: چکیدهٔ مورد انتظار + جای‌گذاری از کلیپ‌بورد، محاسبهٔ MD5/SHA-1/SHA-256/SHA-512 با کپی و نشان «مطابقت دارد/ندارد»
  - **جزئیات**: نوع/محتوا/اندازه/ابعاد، چهار زمان، برچسب رنگی، امتیاز ستاره و توضیح (همه در `.mfm.json` همان پوشه)
  - کپی مسیر و «نمایش در فایل‌منیجر سیستم» در پایین پنجره
  - هر تغییر (مجوز، برچسب، ستاره، توضیح) فهرست پشت پنجره را فوراً دوباره می‌خواند؛ برچسب رنگی هم در ردیف فهرست و هم روی کاشی شبکه دیده می‌شود
- [x] فونت رابط کاربری از تنظیمات → ظاهر: نام فونت نصب‌شده (با پیشنهاد از فونت‌های رایج) یا خالی برای وزیرمتن؛ خانوادهٔ تکی خودکار با وزیرمتن برای پوشش فارسی ترکیب می‌شود و نمونهٔ زنده کنارش دیده می‌شود
- [x] نشان‌کردن پوشهٔ انتخاب‌شده در سایدبار از ستاره یا منوی پوشه (و برداشتنش)؛ بدون انتخاب، پوشهٔ باز نشان می‌شود؛ کشیدن پوشه از پنل و رها کردن آن روی سایدبار (هر جای ستون، از جمله بخش Places) هم آن را نشان می‌کند — حین درگ کل سایدبار هایلایت می‌شود و زیر Places پیام «پوشه را رها کن تا نشان شود» می‌آید
- [x] نوار آبی «پنل فعال» فقط در چیدمان دوپنجره دیده می‌شود
- [x] تغییر عرض بین دو پنجره در حالت دوپنجره با کشیدن خط جداکننده (Splitter) با ماوس؛ دوبار کلیک عرض را به ۵۰/۵۰ برمی‌گرداند
- [x] مدیر فایل پیش‌فرض سیستم: امکان بررسی و تنظیم برنامه به عنوان مدیر فایل پیش‌فرض سیستم (از تنظیمات → راه‌اندازی)
- [x] نشان پیوند نمادین: یک زنجیر نازک و کم‌رنگ کنار نام (نه بج)
- [x] کلید منوی کیبورد (Menu / Shift+F10) همان منوی راست‌کلیک انتخاب را باز می‌کند
- [x] «باز کردن با…» از فهرست برنامه‌های .desktop همین سیستم + «برنامهٔ پیش‌فرض»؛ اگر پیش‌فرض باز نشود، پنجرهٔ انتخاب باز می‌شود
- [x] پیش‌نمایش متن با رنگ‌آمیزی (JSON/کد) و استخراج واقعی متن Word/Excel/PowerPoint (بدون XML خام؛ خالی ⇒ «بدون پیش‌نمایش»)
- [x] نوار بندانگشتی گالری همیشه تصویر فعال را وسط خودش می‌آورد
- [x] باز کردن فایل با برنامهٔ پیش‌فرض سیستم
- [x] ویرایشگر متن داخلی برای `txt`/`md`/`log` و فایل‌های بدون پسوند: Enter یا دوبار کلیک بازش می‌کند، F4 هر فایلی را می‌دهد، ذخیرهٔ اتمیک با Ctrl+S
- [x] ریشه‌ها: `/` و خانه و دیسک‌های جانبی (لینوکس) · حروف درایو (ویندوز)

## فاز ۲ — سرعت و راحتی روزمره ✅

- [x] Ctrl+A انتخاب همه · Esc پاک‌کردن انتخاب و صافی
- [x] نوار فرمان: چیدمان دلخواه، حالت «فقط آیکون / آیکون و متن / فقط متن»، و در عرض کم دکمه‌های جامانده به «…» می‌روند (بدون بریدن یا اسکرول بی‌صدا)
- [x] پیمایش با کیبورد مثل Krusader: ↑/↓ ردیف، Shift+↑/↓ بازه، PgUp/PgDn/Home/End، ← پوشهٔ بالاتر، → باز کردن (در نمای شبکه فلش‌ها خانه‌به‌خانه می‌روند)
- [x] تعداد خطوط نام در نمای شبکه قابل تنظیم (۱ تا ۴ خط؛ کاشی با آن بلندتر می‌شود)
- [x] تاریخچهٔ رفت‌وبرگشت در هر پنجره (Alt+← / Alt+→)
- [x] صافی زندهٔ همان پوشه در نوار مسیر (Ctrl+F)؛ Enter اولین نتیجه را باز می‌کند
- [x] نمای شبکه با بندانگشتی واقعی تصاویر (پروتکل داخلی `mfm://`)
- [x] نمای شبکه سایزبندی دارد: کاشی کوچک/متوسط/بزرگ/بزرگ‌تر و ۱ تا ۴ خط نام؛ بندانگشتی و گلیف پوشه با کاشی بزرگ می‌شوند
- [x] آیکون پوشه‌ای که دلفین در `.directory` یا ویندوز در `desktop.ini` گذاشته، خوانده و همان‌جا نمایش داده می‌شود (آن فایل‌ها فقط خوانده می‌شوند)
- [x] آیکون فایل و پوشه از آیکون‌ست **Pure که داخل برنامه embed شده** می‌آید (data URL، بدون وابستگی به سیستم‌عامل)؛ در تنظیمات می‌شود آیکون‌ست سیستم‌عامل یا گلیف‌های خطی را انتخاب کرد — دور آیکون‌ها کادر نیست؛ آیکون پوشهٔ تعیین‌شده در `.directory` (دلفین) یا `desktop.ini` (ویندوز) هم خوانده و نشان داده می‌شود
- [x] رنگ پوشه از واریانت‌های رنگی Pure استفاده می‌کند (قرمز/نارنجی/زرد/سبز/آبی/بنفش/صورتی/خاکستری) و با آیکون‌ست خطی همان گلیف رنگ‌شده می‌ماند
- [x] نوار کنار: درخت پوشه‌ها با باز شدن تنبل + پوشه‌های نشان‌شده (Ctrl+D)
- [x] فهرست نشان‌ها بدون سایدبار هم در دسترس است: فلش کوچک کنار ستاره در نوار آدرس هر پنل یک منوی «نشان‌ها» باز می‌کند و با کلیک، همان پنل به پوشه می‌رود
- [x] ستون «نوع»: پوشه/تصویر/ویدئو/صدا/بایگانی/کد/متن/سند/PDF/صفحه گسترده/ارائه
- [x] اندازهٔ پوشه به‌صورت تقاضایی (F9؛ سقف ۲۰۰هزار فایل یا ۴ ثانیه)
- [x] ذخیرهٔ وضعیت پنجره/تب‌ها/تم/نما/نشان‌ها بین اجراها (`state.json` در userData)
- [x] اندازه و جای پنجره در `window.json`؛ اگر آن نمایشگر وصل نباشد، پنجره روی نمایشگر اصلی و وسط صفحه باز می‌شود
- [x] یک نوار اقدام (نوار فرمان) به‌جای سه نوار تکراری: نوار پنل فقط ناوبری/جست‌وجو دارد و نوار وضعیت فقط اطلاعات می‌دهد؛ اقدام‌ها از فهرست فرمان‌ها قابل‌شخصی‌سازی‌اند
- [x] رابط فارسی RTL با فونت Vazirmatn (از npm، بدون CDN)، ارقام فارسی؛ مسیرها و نام فایل‌ها چپ‌چین
- [x] آیکون خطی برای هر نوع فایل و هر دکمه (`Icons.tsx`، بدون کتابخانهٔ آیکون)
- [ ] پرش با تایپ (type-ahead) به ردیف هم‌نام
- [ ] ستون‌های دلخواه بیشتر: مجوزها، مالک، تعداد لینک، ابعاد تصویر
- [ ] اندازه و فونت قابل‌تنظیم در UI

## فاز ۳ — عملیات فایل در حد DOpus (بخش عمده انجام شد)

- [x] صف عملیات: پیشرفت بایتی، سرعت، مکث/ادامه، لغو، گزارش خطا (نوار «عملیات‌ها» بالای نوار وضعیت)
- [x] جست‌وجو: نام با wildcard/regex، متن داخل محتوا (موتور فیلتر اندازه/تاریخ هم دارد، UI آن را ندارد) — با بودجهٔ زمانی ۲.۵ ثانیه، ترتیب سطحی (BFS) و رد‌کردن پوشه‌های مخفی/`node_modules`، پس روی خانه هم چند ثانیه‌ای جواب می‌دهد
- [x] فشرده‌سازی با دیالوگ: نام آرشیو، سطح (سریع/عادی/حداکثر)، مقصد (همین پوشه یا پنجرهٔ مقابل)
- [x] استخراج با دیالوگ: انتخاب مقصد؛ هیچ فایل موجودی بازنویسی نمی‌شود (نام تکراری «(۲)» می‌گیرد)
- [x] کشیدن پوشه روی «مکان‌ها» آن را نشان (bookmark) می‌کند
- [x] یابندهٔ فایل‌های تکراری با sha256، گروه‌بندی و شمارهٔ گروه در ستون نوع
- [x] تغییر نام گروهی: الگو با شماره‌گذاری و صفر پیشرو، regex با گروه‌ها، پیش‌نمایش زنده، هشدار نام تکراری
- [x] Undo برای انتقال، تغییر نام و پوشهٔ نو (Ctrl+Z) — حذف و سطل بازیافت هنوز برنمی‌گردد
- [x] نمای تخت (همهٔ فایل‌های زیرشاخه یک‌جا، با نام نسبی)
- [ ] کپی/انتقال با فیلتر (فقط جدیدترها، فقط هم‌اندازه‌ها، حذف پس از انتقال)
- [ ] همگام‌سازی دو پوشه (copy missing / mirror / newer-only)
- [ ] برچسب رنگی و متنی روی فایل
- [x] SHA-256 برای انتخاب (از منوی راست‌کلیک؛ نتیجه در حافظه کپی می‌شود)
- [ ] تقسیم/چسباندن فایل، مقایسهٔ دو فایل، MD5

## تنظیمات و ساختار پنجره

- [x] پنجرهٔ تنظیمات با دسته‌های کنار (ظاهر، نمایش، چیدمان، عملیات، راه‌اندازی، پیشرفته) — نقشهٔ کامل در `docs/PREFERENCES.md`
- [x] حالت تک‌پنجره (دوپنجره اجباری نیست) با حفظ مقصد کپی/انتقال و نمایش آن در نوار وضعیت
- [x] تک‌نمونه (single instance): اجرای دوباره پنجرهٔ موجود را جلو می‌آورد و مسیر آرگومان را باز می‌کند
- [x] تب کامل: Ctrl+T/W/Shift+T/Ctrl+Tab/Ctrl+۱…۹، تب سنجاق‌شده، جابه‌جایی با کشیدن، منوی تب (سنجاق، تکراری، بستن، بستن بقیه، بستن بعدی‌ها، کپی مسیر)، بستن با کلیک وسط، جای تب نو قابل‌تنظیم
- [x] تأیید پیش از حذف (قابل خاموش‌کردن)، حذف پیش‌فرض با سطل، رفتار دوبار کلیک (اجرا/گالری/پیش‌نمایش)
- [x] «پوشه‌ها اول» و ستون «نوع» قابل خاموش‌کردن
- [x] ستون‌های دلخواه: نوع، اندازه، تاریخ، مجوز (rwx)، مالک (uid:gid)، تعداد لینک، ابعاد تصویر — با روشن/خاموش و ترتیب دلخواه، و اسکرول افقی وقتی پنل باریک است
- [x] قالب اندازه (خوانا / بایت دقیق) و قالب تاریخ (شمسی / میلادی / فقط ساعت) + ثانیه
- [x] نوار آدرس با Ctrl+L یا دابل‌کلیک روی breadcrumb، در همان جای breadcrumb (فیلد همیشه LTR، حتی در فارسی؛ `~` هم قبول می‌شود)
- [x] نوار وضعیت: مجموع حجم انتخاب + فضای آزاد همان حجم
- [ ] کشیدن عرض ستون‌ها، «نمای هر پوشه»، تکمیل خودکار مسیر
- [ ] ویرایشگر کلید میان‌بر و نوار ابزار دلخواه (فاز D)

## پنجره و ظاهر (خارج از فازبندی؛ درخواست مستقیم)

- [x] تایتل‌بار خودِ برنامه (frameless) با کوچک/بزرگ/بستن و دوبار کلیک برای بزرگ‌کردن — قابل جابه‌جایی با تایتل‌بار سیستم
- [x] گوشه‌های گرد پنجره (پنجرهٔ شفاف + شعاع CSS؛ روی کامپوزیتور واقعی، شفاف دیده می‌شود)
- [x] سایدبار دو حالته: چسبیده یا شناور (کارت روی پنجره‌ها با پردهٔ تیره) + نمایش/پنهان
- [x] دکمهٔ پین در سر سایدبار («مکان‌ها») برای شناور/چسبیده کردن سریع، بدون رفتن به تنظیمات
- [x] پنل تنظیمات در خود برنامه (تایتل‌بار، گوشه‌ها، سایدبار، تم)

- [x] رنگ پوشه و آیکون پوشه، مستقل از سیستم‌عامل، در فایل مخفی `.mfm.json` داخل همان پوشه — روی **پوشه‌های انتخاب‌شده** اعمال می‌شود (چندتایی)، نه پوشهٔ جاری
- [x] «از فهرست پنهان کن» برای یک پوشه (مثل ویژگی hidden دلفین) بدون تغییر نام؛ با نمایش فایل‌های مخفی برمی‌گردد
- [x] آیکون از پک‌های آمادهٔ KDE (Breeze/Papirus/Oxygen/Adwaita/…) با انتخاب پک، جست‌وجوی نام و افزودن پک دلخواه
- [x] گالری تصاویر تمام‌پنجره: پیمایش با ← →، Home/End، بزرگ‌نمایی +/-، چرخش R، پخش خودکار Space، تمام‌صفحه F، نوار بندانگشتی
- [x] ویرایش سادهٔ تصویر در گالری: چرخش ۹۰ درجه، آینه افقی/عمودی، برش با کشیدن مستطیل، تغییر اندازه با حفظ نسبت، ذخیره به‌عنوان کپی یا جایگزینی فایل اصلی
- [x] پیش‌نمایش در پنجرهٔ مقابل با F3 (و پنل کنار) + پیمایش تصویرها داخل خود پیش‌نمایش

## فاز ۵ — یکپارچگی با میزکار (شروع شد)

- [x] منوی راست‌کلیک: اجرا، پیش‌نمایش، مرور آرشیو، کپی/انتقال، تغییر نام (تکی و گروهی)، سطل، حذف قطعی، کپی مسیر، SHA-256، اندازه، ظاهر پوشه، تب نو — با آیکون و کلید میان‌بر
