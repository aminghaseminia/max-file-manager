# Directory Opus feature matrix → max-file-manager

مرجع: امکانات Directory Opus 13 (ویندوز). ستون «فاز» یعنی کِی نوبتش می‌شود؛ هر چیزی که تیک ندارد هنوز پیاده نشده است.

## فاز ۱ — هستهٔ یک فایل‌منیجر روزمره (v0.1، همین حالا)

- [x] دو پنجرهٔ مستقل (source / destination)
- [x] تب در هر پنجره
- [x] مرور واقعی پوشه، breadcrumb، بالا/رفرش، Backspace
- [x] لیست ستون‌دار (Name/Size/Modified) با مرتب‌سازی و «پوشه‌ها اول»
- [x] لیست مجازی‌شده — پوشهٔ ۱۰۰هزار فایلی روان بماند
- [x] انتخاب تک/چندتایی (Ctrl، Shift)، انتخاب همه با Ctrl+A *(معوق — پایین)*
- [x] کپی F5 · انتقال F6 · پوشهٔ نو F7 · سطل بازیافت F8 · حذف قطعی Shift+F8 · تغییر نام F2
- [x] نمایش/پنهان‌کردن فایل‌های مخفی (Ctrl+H)
- [x] تم تیره/روشن
- [x] باز کردن فایل با برنامهٔ پیش‌فرض سیستم
- [x] ریشه‌ها: `/` و خانه و دیسک‌های جانبی (لینوکس) · حروف درایو (ویندوز)

## فاز ۲ — سرعت و راحتی روزمره (v0.2)

- [ ] Ctrl+A انتخاب همه · Esc پاک‌کردن انتخاب
- [ ] تاریخچهٔ رفت‌وبرگشت در هر پنجره (Alt+← / Alt+→)
- [ ] نوع‌کردن برای پرش (type-ahead) و فیلتر زندهٔ همان پوشه
- [ ] نمایش آیکون/تصویر بندانگشتی (grid view) در کنار list view
- [ ] نوار کنار: درخت پوشه‌ها (نه فقط ریشه‌ها)، پوشه‌های دلخواه (bookmarks)
- [ ] ستون‌های قابل‌تنظیم: پسوند، نوع، مجوزها، مالک، تعداد لینک، ابعاد تصویر
- [ ] اندازهٔ پوشه به‌صورت تقاضایی (محاسبه با کلیک روی ستون)
- [ ] ذخیرهٔ وضعیت پنجره/تب‌ها/ستون‌ها بین اجراها (JSON در userData)
- [ ] فونت و اندازهٔ فونت قابل‌تغییر + زبان فارسی/RTL در UI

## فاز ۳ — عملیات فایل در حد DOpus (v0.3)

- [ ] صف عملیات با پیشرفت، سرعت، مکث/ادامه/لغو و گزارش خطا
- [ ] کپی/انتقال با فیلتر (فقط جدیدترها، فقط هم‌اندازه‌ها، حذف پس از انتقال)
- [ ] کارهای تکراری/همگام‌سازی دو پوشه (sync: copy missing / mirror / newer-only)
- [ ] جست‌وجو: نام با wildcard/regex، محتوا (grep)، فیلتر اندازه/تاریخ، «یافتن فایل‌های تکراری» با hash
- [ ] تغییر نام گروهی: شماره‌گذاری، regex با گروه‌ها، جابه‌جایی بخش‌ها، پیش‌نمایش زنده
- [ ] Undo برای حذف/انتقال/تغییر نام (تاریخچهٔ عملیات در همان نشست)
- [ ] پوشه‌های مجازی/فیلترشده: Flat view (همهٔ فایل‌های زیرشاخه یک‌جا)، فقط یک نوع فایل
- [ ] برچسب رنگی، ستاره، برچسب متنی روی فایل (sidecar یا xattr)
- [ ] checksum (MD5/SHA)، تقسیم/چسباندن فایل، مقایسهٔ دو فایل

## فاز ۴ — بایگانی و پروتکل‌ها (v0.4)

- [ ] zip/tar/gz/7z مثل پوشه مرور شوند (کپی داخل/بیرون)
- [ ] SFTP/FTP و S3 به‌عنوان محل (address bar: `sftp://…`)
- [ ] کپی مستقیم به گوشی/دستگاه (MTP) — در لینوکس از gvfs
- [ ] اتصال به Google Drive / OneDrive به‌عنوان محل مجازی

## فاز ۵ — یکپارچگی با میزکار (v0.5)

- [ ] KDE: منوی سرویس Dolphin، آیکون در system tray، MIME/thumbnailer، باز شدن با «Open with»
- [ ] ویندوز: منوی راست‌کلیک Explorer، Send To، pin در taskbar، باز شدن با «Open with»
- [ ] کشیدن و رها کردن بین پنجره‌ها و از/به فایل‌منیجر سیستم
- [ ] منوی راست‌کلیک کامل (DOpus-style، قابل‌تنظیم)
- [ ] نوار ابزار قابل‌تنظیم + کلیدهای میان‌بر قابل‌تنظیم
- [ ] نمایش‌دهندهٔ داخلی (متن/تصویر/PDF/صدا/ویدیو) در پنل کنار
- [ ] چند زبانه: فارسی (RTL) / انگلیسی / عربی

## معوق و آگاهانه (تصمیم بعدی)

- چند-پنجره‌ای بیش از دو (layout های ذخیره‌شده) — سنگین است، بعد از فاز ۳
- اسکریپت‌نویسی کاربر (DOpus JScript) — جایگزین مدرن: پلاگین JS در خود برنامه
- ایندکس Everything-مانند برای جست‌وجوی آنی کل دیسک — نیاز به سرویس پس‌زمینه دارد
- همگام‌سازی ابری دوطرفه (Conflict resolution) — خارج از محدودهٔ یک فایل‌منیجر
