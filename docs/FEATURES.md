# Directory Opus feature matrix → max-file-manager

مرجع: امکانات Directory Opus 13 (ویندوز). ستون «فاز» یعنی کِی نوبتش می‌شود؛ هر چیزی که تیک ندارد هنوز پیاده نشده است.

## فاز ۱ — هستهٔ یک فایل‌منیجر روزمره ✅

- [x] دو پنجرهٔ مستقل (مبدأ / مقصد)
- [x] تب در هر پنجره
- [x] مرور واقعی پوشه، breadcrumb، بالا/رفرش، Backspace
- [x] لیست ستون‌دار با مرتب‌سازی و «پوشه‌ها اول»
- [x] لیست مجازی‌شده — پوشهٔ ۱۰۰هزار فایلی روان بماند
- [x] انتخاب تک/چندتایی (Ctrl، Shift)
- [x] کپی F5 · انتقال F6 · پوشهٔ نو F7 · سطل بازیافت F8 · حذف قطعی Shift+F8 · تغییر نام F2
- [x] نمایش/پنهان‌کردن فایل‌های مخفی (Ctrl+H)
- [x] تم تیره/روشن
- [x] باز کردن فایل با برنامهٔ پیش‌فرض سیستم
- [x] ریشه‌ها: `/` و خانه و دیسک‌های جانبی (لینوکس) · حروف درایو (ویندوز)

## فاز ۲ — سرعت و راحتی روزمره ✅

- [x] Ctrl+A انتخاب همه · Esc پاک‌کردن انتخاب و صافی
- [x] تاریخچهٔ رفت‌وبرگشت در هر پنجره (Alt+← / Alt+→)
- [x] صافی زندهٔ همان پوشه در نوار مسیر (Ctrl+F)؛ Enter اولین نتیجه را باز می‌کند
- [x] نمای شبکه با بندانگشتی واقعی تصاویر (پروتکل داخلی `mfm://`)
- [x] نوار کنار: درخت پوشه‌ها با باز شدن تنبل + پوشه‌های نشان‌شده (Ctrl+D)
- [x] ستون «نوع»: پوشه/تصویر/ویدئو/صدا/بایگانی/کد/متن/سند/PDF/صفحه گسترده/ارائه
- [x] اندازهٔ پوشه به‌صورت تقاضایی (F9؛ سقف ۲۰۰هزار فایل یا ۴ ثانیه)
- [x] ذخیرهٔ وضعیت پنجره/تب‌ها/تم/نما/نشان‌ها بین اجراها (`state.json` در userData)
- [x] رابط فارسی RTL با فونت Vazirmatn (از npm، بدون CDN)، ارقام فارسی؛ مسیرها و نام فایل‌ها چپ‌چین
- [x] آیکون خطی برای هر نوع فایل و هر دکمه (`Icons.tsx`، بدون کتابخانهٔ آیکون)
- [ ] پرش با تایپ (type-ahead) به ردیف هم‌نام
- [ ] ستون‌های دلخواه بیشتر: مجوزها، مالک، تعداد لینک، ابعاد تصویر
- [ ] اندازه و فونت قابل‌تنظیم در UI

## فاز ۳ — عملیات فایل در حد DOpus (بخش عمده انجام شد)

- [x] صف عملیات: پیشرفت بایتی، سرعت، مکث/ادامه، لغو، گزارش خطا (نوار «عملیات‌ها» بالای نوار وضعیت)
- [x] جست‌وجو: نام با wildcard/regex، متن داخل محتوا (موتور فیلتر اندازه/تاریخ هم دارد، UI آن را ندارد)
- [x] یابندهٔ فایل‌های تکراری با sha256، گروه‌بندی و شمارهٔ گروه در ستون نوع
- [x] تغییر نام گروهی: الگو با شماره‌گذاری و صفر پیشرو، regex با گروه‌ها، پیش‌نمایش زنده، هشدار نام تکراری
- [x] Undo برای انتقال، تغییر نام و پوشهٔ نو (Ctrl+Z) — حذف و سطل بازیافت هنوز برنمی‌گردد
- [x] نمای تخت (همهٔ فایل‌های زیرشاخه یک‌جا، با نام نسبی)
- [ ] کپی/انتقال با فیلتر (فقط جدیدترها، فقط هم‌اندازه‌ها، حذف پس از انتقال)
- [ ] همگام‌سازی دو پوشه (copy missing / mirror / newer-only)
- [ ] برچسب رنگی و متنی روی فایل
- [x] SHA-256 برای انتخاب (از منوی راست‌کلیک؛ نتیجه در حافظه کپی می‌شود)
- [ ] تقسیم/چسباندن فایل، مقایسهٔ دو فایل، MD5

## تنظیمات و ساختار پنجره

- [x] پنجرهٔ تنظیمات با دسته‌های کنار (ظاهر، نمایش، چیدمان، عملیات، راه‌اندازی، پیشرفته) — نقشهٔ کامل در `docs/PREFERENCES.md`
- [x] حالت تک‌پنجره (دوپنجره اجباری نیست) با حفظ مقصد کپی/انتقال و نمایش آن در نوار وضعیت
- [x] تک‌نمونه (single instance): اجرای دوباره پنجرهٔ موجود را جلو می‌آورد و مسیر آرگومان را باز می‌کند
- [x] تب: Ctrl+T تب نو، Ctrl+W بستن تب، Ctrl+Tab تب بعدی
- [x] تأیید پیش از حذف (قابل خاموش‌کردن)، حذف پیش‌فرض با سطل، رفتار دوبار کلیک (اجرا/گالری/پیش‌نمایش)
- [x] «پوشه‌ها اول» و ستون «نوع» قابل خاموش‌کردن
- [x] ستون‌های دلخواه: نوع، اندازه، تاریخ، مجوز (rwx)، مالک (uid:gid)، تعداد لینک، ابعاد تصویر — با روشن/خاموش و ترتیب دلخواه، و اسکرول افقی وقتی پنل باریک است
- [x] قالب اندازه (خوانا / بایت دقیق) و قالب تاریخ (شمسی / میلادی / فقط ساعت) + ثانیه
- [x] نوار آدرس با Ctrl+L (مسیر تایپ‌شده، `~` هم قبول می‌شود)
- [x] نوار وضعیت: مجموع حجم انتخاب + فضای آزاد همان حجم
- [ ] کشیدن عرض ستون‌ها، «نمای هر پوشه»، تکمیل خودکار مسیر
- [ ] ویرایشگر کلید میان‌بر و نوار ابزار دلخواه (فاز D)
- [ ] پشتیبان‌گیری/بازگردانی تنظیمات (فاز I)

## پنجره و ظاهر (خارج از فازبندی؛ درخواست مستقیم)

- [x] تایتل‌بار خودِ برنامه (frameless) با کوچک/بزرگ/بستن و دوبار کلیک برای بزرگ‌کردن — قابل جابه‌جایی با تایتل‌بار سیستم
- [x] گوشه‌های گرد پنجره (پنجرهٔ شفاف + شعاع CSS؛ روی کامپوزیتور واقعی، شفاف دیده می‌شود)
- [x] سایدبار دو حالته: چسبیده یا شناور (کارت روی پنجره‌ها با پردهٔ تیره) + نمایش/پنهان
- [x] پنل تنظیمات در خود برنامه (تایتل‌بار، گوشه‌ها، سایدبار، تم)
- [x] نوار وضعیت با دکمه‌های آیکون‌دار برای عملیات‌ها (کپی، انتقال، نام، پوشه، سطل، اندازه، بازگردانی)
- [x] رنگ پوشه و آیکون پوشه، مستقل از سیستم‌عامل، در فایل مخفی `.mfm.json` داخل همان پوشه
- [x] آیکون از پک‌های آمادهٔ KDE (Breeze/Papirus/Oxygen/Adwaita/…) با انتخاب پک، جست‌وجوی نام و افزودن پک دلخواه
- [x] گالری تصاویر تمام‌پنجره: پیمایش با ← →، Home/End، بزرگ‌نمایی +/-، چرخش R، پخش خودکار Space، تمام‌صفحه F، نوار بندانگشتی
- [x] ویرایش سادهٔ تصویر در گالری: چرخش ۹۰ درجه، آینه افقی/عمودی، برش با کشیدن مستطیل، تغییر اندازه با حفظ نسبت، ذخیره به‌عنوان کپی یا جایگزینی فایل اصلی
- [x] پیش‌نمایش در پنجرهٔ مقابل با F3 (و پنل کنار) + پیمایش تصویرها داخل خود پیش‌نمایش
- [ ] نمایش‌دهندهٔ آیکون برای فایل‌ها (فعلاً فقط پوشه‌ها)
- [ ] چند پوشهٔ آیکون هم‌زمان در یک نما (thumbnailerها)

## فاز ۴ — بایگانی و پروتکل‌ها (شروع شد)

- [x] zip و tar/tar.gz/tgz مثل پوشه مرور شوند (فهرست تخت با نام نسبی) و با F5 در پنجرهٔ مقابل استخراج شوند
- [x] یابنده/بازکن بایگانی بدون ابزار سیستم (fflate + پارسر tar داخلی)، سقف ۲۵۶ مگابایت
- [ ] 7z/rar و بایگانی رمزدار
- [ ] پیمایش درختی داخل بایگانی (پوشه‌های آرشیو مثل پوشه باز شوند)
- [ ] SFTP/FTP و S3 به‌عنوان محل (`sftp://…`)
- [ ] کپی مستقیم به گوشی/دستگاه (MTP) — در لینوکس از gvfs
- [ ] Google Drive / OneDrive به‌عنوان محل مجازی

## فاز ۵ — یکپارچگی با میزکار (شروع شد)

- [x] منوی راست‌کلیک: اجرا، پیش‌نمایش، مرور آرشیو، کپی/انتقال، تغییر نام (تکی و گروهی)، سطل، حذف قطعی، کپی مسیر، SHA-256، اندازه، ظاهر پوشه، تب نو — با آیکون و کلید میان‌بر
- [x] کشیدن و رها کردن درونی: ردیف را روی پنجرهٔ مقابل یا روی یک پوشه رها کن (بدون Ctrl = انتقال، با Ctrl = کپی) — از همان صف انتقال رد می‌شود
- [x] رها کردن فایل از برنامه‌های دیگر روی یک پنجره = کپی به همان پوشه
- [x] پنل پیش‌نمایش کنار: متن (تا ۲۰۰KB)، تصویر، صدا، ویدیو + اندازه/تاریخ و دکمهٔ باز کردن
- [ ] کشیدن به بیرون (به Dolphin/Explorer) — نیاز به آیکون drag دارد
- [ ] KDE: منوی سرویس Dolphin، آیکون system tray، MIME/thumbnailer، «Open with»
- [ ] ویندوز: منوی راست‌کلیک Explorer، Send To، pin در taskbar
- [ ] نوار ابزار و کلیدهای میان‌بر قابل‌تنظیم
- [ ] چند زبانه: فارسی (RTL) / انگلیسی / عربی

## معوق و آگاهانه (تصمیم بعدی)

- چند-پنجره‌ای بیش از دو (layout های ذخیره‌شده) — بعد از فاز ۳
- اسکریپت‌نویسی کاربر — جایگزین مدرن: پلاگین JS در خود برنامه
- ایندکس Everything-مانند برای جست‌وجوی آنی کل دیسک — نیاز به سرویس پس‌زمینه
- همگام‌سازی ابری دوطرفه با حل تعارض — خارج از محدودهٔ یک فایل‌منیجر
